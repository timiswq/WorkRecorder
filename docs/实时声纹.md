# 实时本人识别

实时声纹从录音卡蓝牙音频独立处理，不等待字幕定稿。CAM++ 和 Silero 均在本机运行；声纹没有发送到云端。归档录音的分组与命名仍由原有路径处理。

## 连续音频与身份判断

`LiveSpeakerStream` 保持 Opus 解码状态和音频时间轴，Silero 提供语音活动掩码。`LiveVoiceBuffer` 默认使用 5 秒连续 PCM、1 秒步长，主窗口至少需要 3 秒语音，削波比例不得超过 1%。语音掩码用于质量判断，不拼接不相邻话音。初始 4 秒窗口在公开自然语音中出现 2.848 秒有效语音，因此采用设计允许范围内的 5 秒窗口。

推理队列只保留一个正在计算的窗口和一个最新待算窗口。PCM、原始 Opus 和在线向量均有界保留；不会每秒登记一个新说话人或增加本人样本。包格式错误、输入不连续、录音边界和取消会隔离解码状态，过期实例的回调不能恢复旧身份。

`LiveIdentityTracker` 使用窗口连续性确认身份，并用最近约 2 秒语音检查说话人变化。相互重叠的窗口不是独立投票，讲话时长按音频覆盖范围计算。长期本人模板只来自明确人工反馈，临时声音轨迹不会自动教会本人模板。

有效语音不足时暂缓身份确认，恢复讲话后须重新获得至少 1 秒新增音频支持；短暂停顿本身不创建另一位说话人，保留的声音参考仍用于检测真正换人。无效音频、削波或录音流中断则重置轨迹。

本人匹配保留 0.62 相似度门槛和 0.06 显式反例间隔。自动未知声音组不再作为本人身份的强负例，明确的非本人样本和已命名其他人模板参与竞争。这些值属于 CAM++ 当前配置，不可直接套用其他模型的距离阈值。

## 字幕与反馈

稳定短语直接显示在气泡中。声音结果按原音频范围关联发言人标签。新轨迹尚未确认时保留已有的精确句段结果。连续轨迹可支持后续句子，但最新短窗口必须落在当前句子里；跨不同轨迹的混合长句保持未知，晚于句末的另一人不能重标之前整句。

「是我 / 不是我」以点击时已有的本句音频为准。精确句段至少需要 2 秒录音，还须通过有效语音和声纹一致性检查。滚动窗口须落在本句内，通过语音质量检查，覆盖单一轨迹并靠近当前句尾。合格的本人或非本人样本可以参与后续匹配。

其余情况只保存本句的发言人标注。迟到的声纹不会触发补录，标注也不会重置当前说话人的连续跟踪。逐句云端复核可以修订历史正文，人工标注仍与原句关联。

保存滚动窗口时，会一起记录原始 Opus、音频范围、质量、声纹向量，以及该窗口是否可用作本句样本。在内存中确认合格窗口时，还会保存推理所用的 PCM。重启后，历史标注使用持久化的资格。旧资料只有在已有明确反馈保存的 PCM 且窗口未被判为混合或过期时，才会恢复这项资格。

样本一致性采用留一检查：每条样本只与其他样本的模板比较。单样本不能评估一致性；低一致性仅用于设置页提示，不自动删除或改标签。阈值自动校准需要独立本人和真实非本人标注；现有未标注历史不作为准确率或调低阈值的依据。

## 旁路、回退与诊断

启动时设置 `WORKDAY_LIVE_IDENTITY_MODE`：

- `active`：默认，启用新实时身份结果。
- `shadow`：运行滚动识别、记录诊断，保留原显示，不写入新窗口记录。
- `legacy`：关闭滚动分支，使用原句段识别。

`WORKDAY_LIVE_VOICE_REPORT` 指向仓库外 JSONL 文件时，记录窗口质量、分数、判断原因、样本数和纯推理耗时，文件最大约 8 MB；不含字幕、音频和声纹向量。文件仅当前用户可读。

独立实机诊断必须同时设置外部 `WORKDAY_LIBRARY` 和 `WORKDAY_LIVE_VOICE_VALIDATION_ONLY=1`，并提供已绑定的 `WORKDAY_LIVE_VOICE_DEVICE_ID`。该模式不加载钥匙串、不启用云端或 USB 导入、不显示桌面气泡，只订阅已绑定录音卡和查询状态，不发启停录音命令。`WORKDAY_LIVE_VOICE_VALIDATE_CAPTIONS=1` 可同时运行本地字幕；`WORKDAY_LIVE_VOICE_DURATION` 为 15～300 秒，默认 60 秒。设备状态另存到报告路径加 `.device.jsonl`。macOS 对新签名仍可能要求蓝牙授权，未授权时不得把零输入算作实机通过。

## 验证

- `python3 script/live_voice_baseline.py <资料库或快照目录> <仓库外结果.json>`：只读样本与处理路径审计。
- `./script/test.sh --full`：回归、实际模型和公开语音控制。设置外部 `WORKDAY_VOICE_BENCHMARK_OUTPUT` 可同时导出公开长草稿与无停顿换人对照。
- 公开对照的训练音频和被测音频不同。重复编码片段属于构造的功能对照，不代表自然会议或真实佩戴准确率。
- 未人工确认身份的录音只报告处理覆盖率、质量与运行性能。Window Server 系统遮罩覆盖点击位置时，窗口命中测试明确跳过，不关闭遮罩或抢占前台。

实现思路参考 [diart](https://github.com/juanmc2005/diart)、[FluidAudio](https://github.com/FluidInference/FluidAudio)、[Fono](https://github.com/bogdanr/fono) 和 [FASTDIAR](https://github.com/microsoft/fastdiar)；本轮继续使用已有模型和依赖。
