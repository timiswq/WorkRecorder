# 项目基线

从 `main` 的 `baseline-2026-11-17` 继续开发。App 版本为 **0.7.0（20260006）**。11 月 16 日的里程碑安装包仍对应前一日的标签。

## 本次纳入的行为

| 范围 | 当前行为 |
| --- | --- |
| 录音卡 | QS668 / CB08 通过 USB 归档，B3085 / FW925 通过 Wi-Fi 同步原件并生成 WAV。两类卡的蓝牙音频共用字幕和实时声纹入口。 |
| 选卡与同步 | 在设备页浏览候选，选定后切换。USB 首次关联需确认；只用 USB 也可单独选盘。同步执行前核对目标，避免处理其他卡的同名录音。 |
| 字幕与云端处理 | Apple 本机识别可按草稿停顿和句末标点分行并逐句回听。可选 ESP 服务提供实时识别、逐句复核、录后转写及 GPT 内容整理。 |
| 全天回顾 | 后台任务按日期汇总转写与概述进度。录音和概述可分别重试，保留已有文字和处理进度。 |

设置与操作见[使用指南](使用指南.md)，模块分工、迁移和回归入口见[开发指南](开发指南.md)。

## 真机与服务验收边界

- 11 月 17 日已有 FW925 机身按键录制三句口述的短时实测，断句调整后得到三条可回听定稿，仍有错词。长录音、暂停恢复、中途接入、实体多卡切换以及与同次 Wi-Fi 原件的完整对齐仍需实机验收。详见 [Wi-Fi 录音卡开发指南](Wi-Fi录音卡开发指南.md)。
- 此前的 ESP 样例请求覆盖实时识别、逐句复核、归档转写、对话与概述生成。本轮完整回归在本地执行。真实会议的识别与声纹准确率、网络中断恢复及云端费用仍需分别评估。
- VoiceOver、跨 macOS 版本交互、Developer ID 签名和 Apple 公证仍待验收。独立录音卡 SDK 有单独的版本和交付记录。
