# 项目基线

## 当前里程碑

2026-11-16 在 `main` 建立 0.7.0（构建号 20260006）开发基线，标签为 `baseline-2026-11-16`。本版延续 QS668 / CB08 录音卡的 USB 归档校验、本机与云端字幕、逐句回听和按日期整理。

| 相对 0.6.0 的变化 | 使用方式 |
| --- | --- |
| 实时本人识别 | 随连续语音更新判断，用户反馈绑定当前句的音频。设置中可查看样本一致性，确认后可清空本人及非本人样本。 |
| 全天回顾与播放 | 按上午、下午、晚上查看概述、事项与原话，在底栏按钟点定位，跨录音回听或调整倍速。 |
| 处理进度 | 分别查看转写、事项提取、概述生成和排队状态，可按选定日期或单段录音继续或重试。 |
| 桌面状态 | 点击正文可收起单条字幕气泡。菜单栏展示设备与任务状态，Dock 图标随设备状态及待同步数量更新。 |

## 验收边界

- 实体录音卡的长时间录音、启停、暂停恢复及 USB 切换仍需实机验收。独立 SDK 有自己的版本与交付记录。
- 本轮使用本机识别、公开语音和隔离样本。真实会议中的误认率、重叠发言和短句效果仍需人工标注评估。
- 真实云账号的转写质量、计费与断网恢复，以及 VoiceOver 和跨 macOS 版本交互仍待单独验收。
- 本地安装包使用临时签名；Developer ID 分发和 Apple 公证另行办理。
