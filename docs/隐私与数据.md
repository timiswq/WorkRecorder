# 隐私与数据

本文依据仓库实现说明数据存储和处理路径。自行修改源码、选择同步目录或启用外部服务后，实际数据范围可能随之改变。

## 保存在本机的内容

默认资料库为 `~/Documents/工作留声/`，可在「设置 → 本地归档」切换：

- `Records/`：完整录音、转写、原话时间信息、处理进度与音频剪辑。
- `Days/`：按天组织的事项、决定、任务、摘要与人工归属。
- `Sync/`：同步索引、字幕历史、回听音频、声纹数据库与人工确认样本。

实时字幕与对应回听缓存保留最近 24 小时。声纹特征与反馈语音存储在自己的资料库中。偏好设置使用 macOS UserDefaults；ESP API Key 使用 macOS 钥匙串，源码不提供共享密钥。

这些本地文件包含对话与身份信息；本地存储不等于应用层加密。资料库若放在 iCloud、网盘或共享卷中，还会受到相应同步与访问规则影响。备份、共享和清理前先确认目录与权限。

## 云端何时接收数据

云端功能默认关闭。用户在「设置 → 语音识别」开启并配置自己的 API Key 后，按选择调用 ESP 服务：

| 功能 | 发出的内容 |
| --- | --- |
| 云端实时字幕 | 来自录音卡的实时音频，经安全 WebSocket 发送给所选识别模型 |
| 逐句字幕复核 | 本机定稿字幕对应的音频片段，在 HTTPS 请求中直接提交 |
| 完整录音转写 | 分段音频与转写请求所需参数 |
| 对话整理与全天摘要 | 转写文字、用于组织事项的对话与上下文 |

ESP API Key 用于向 `esp.xkw.cn` 的 HTTPS 和 WebSocket 接口认证，单独保存在钥匙串的 ESP 账号项中。

云端音频的保留时间、服务商日志与训练使用规则取决于服务商当前条款和账号配置。应用不会因关闭开关而撤回此前已经提交的数据；不要把本地缓存清理视为云端删除确认。启用前应自行核对服务商的隐私、保留和计费政策。

## 录音卡同步与备份

QS668 / CB08 的 USB 自动同步会在完整原件复制、大小与 SHA-256 校验后，清理卡内对应 WAV / OPUS 副本。归档成功、卡内清理和文字处理分别记录。第一次使用前请阅读[使用指南](使用指南.md)，并备份重要录音。

B3085 / FW925 的 Wi-Fi 同步只读取卡内已保存的文件。Mac 在本地保留设备原件和解码 WAV。实时字幕和归档录音使用各自的云端识别设置。

备份整个资料库可保留音频、摘要、人工整理和声纹。删除一条字幕或隐藏气泡不等于删除所有原件及缓存；不要只根据界面隐藏状态判断数据已清除。重新编译或清理开发缓存不应删除用户资料库、钥匙串或其他 App 数据。

## 公开反馈与日志

提交 Issue、截图或复现资料前，请移除姓名、原话、录音、声纹、API Key、设备授权码、序列号和带签名 URL。优先使用 `script/make_demo.py` 生成的合成音频，并将样本和截图保存在仓库外。公开仓库不附带私人验收资料库。

发现非预期上传或隐私泄露时，按[安全报告流程](../SECURITY.md)私下报告。
