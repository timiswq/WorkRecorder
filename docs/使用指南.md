# 工作留声使用指南

主窗口顶部用一行原生窗口工具栏显示录音卡与 Mac 任务：左侧是录音、时长和电量，点击可进入录音卡详情；右侧用任务图标集中承载保存、转写、提取事项和生成概述；运行中用小蓝点提示，需要处理的失败用警示图标提示，悬停或点击可看具体内容并恢复操作。切换日期和页面时，全局状态持续可见。菜单栏使用同一套状态与操作。后台转写失败不会把正在录音的卡标记成硬件故障；收起错误横幅只隐藏提示，任务中的失败和重试入口仍保留。

侧栏仅保留必要的设备与录音提示。「全天事项」不再常驻显示整理转圈和更新蓝点；后台任务集中在右上角。点击仍可打开最近有内容更新的日期，实际查看后清除对应版本。「实时字幕」在设备确认录音并收到音频时，用四个小方块表示真实输入音量，环境安静时保留空格轮廓；收不到音频时显示短横线，暂停、停止、连接中和未知状态分别表达。电平不依赖字幕识别开关，不使用呼吸动画。「原始录音」显示已知待同步段数，等待 USB、正在录音或清单过期时仍保留上次发现的数量，悬停可查看说明；不完整清单用「≥」表示已发现的至少数量。排除正在录制或待确认保存的文件，同一录音的配对文件合并计算；保存并校验完成后减数，无已知待同步项时隐藏。进入原始录音页可直接查看待同步清单、保存进度和同步操作，录音卡入口不挂数字。

「全天事项」以日期、概述和分时记录为主。中间列表顶部固定显示日期、日历与前后切换，历史日期可点「今天」；跨年份时显示年份。概述默认最多四行，长内容可展开，决定与待办放入「更多信息」。上午、下午、晚上默认展开，空时段不显示；每条记录先显示时间、主题和一句预览，不重复标记整理状态或句数。右侧详情从自身标题开始，默认阅读原话。同一发言人的连续原话合并显示身份标签，仍可逐句回听和操作发言人。

底部统一提供播放、按钟点查找、速度和「录音 N」来源菜单。时间尺标出实际录音区间，点击空档定位到下一段可用音频；连续播放自动跳过空档。同一天不再重复日期，跨日期播放时显示来源日期并可返回。原件列表可从底栏查看原文、播放原录音或在访达中显示。窗口缩小时自动收紧播放控件，保留日期、来源和核心播放入口。

Dock 小助手随录音卡状态自动切换：未连接、连接中、待确认、未录音、正在录音、暂停、保存中和 USB 文件连接。身体下方的符号表示设备状态；未连接只表示 Mac 暂时无法确认卡上状态，USB 图标只表示文件连接。右上角系统角标同步显示「原始录音」的待同步数量，清单不完整时同样使用「≥」，数量超过 99 时显示「99+」。有角标时显示无嘴的提醒双眼，角标清空或暂不显示时恢复原表情；数字由 macOS 单独绘制。关闭主窗口后仍会更新。录音状态、音量、整理进度、更新蓝点和错误状态不增加 Dock 角标。

顶部以电池图标与百分比显示电量，充电时显示「充电中」；设备名在设备详情中查看。正在浏览其他页面时，录音卡新开始录音会将主窗口切到实时字幕并跟随最新内容：支持机身开始按键，也支持查询确认从未录音变为录音。暂停恢复、重连时首次获取状态和音频文件边界变化不会触发跳转；已经在字幕页回看时保留当前阅读位置。

主窗口与菜单栏从录音卡最近回复的时长开始逐秒计时，收到新回复时校准，暂停时停住。连续 10 秒未收到时长回复时，不再继续推算，设备页和菜单栏提示「时长暂未更新」。电量取自最近一次有效回复。USB 接入会暂停蓝牙音频和实时字幕，App 无法确认此时卡上是否仍在录音，请查看卡上指示。「录音卡」页先显示原件保存结果和当前可执行操作，再显示连接影响与 Mac 任务；绑定、容量、固件、磁盘名和设备设置放在折叠详情中。文件已保存、卡内副本已删除、文字整理已完成分别表达。完成文件操作并在访达中推出磁盘后，再断开 USB 恢复蓝牙字幕。

- **归档录音。** 在「设置 → 录音卡」绑定设备，在录音卡上启停录音。通过 USB 接入 Mac 后，App 将已保存的录音复制到资料库，核对文件大小和 SHA-256 后清理卡内对应副本。关闭自动同步时，在主窗口左侧的「录音卡」点「立即同步」。窗口右上角的菜单也可以导入本地音频。
- **查看全天事项。** 点日期打开日历，有录音的日期带圆点；点上午、下午、晚上可收起对应时段。一场会议可引用多份录音，零散原话以「对话片段」保留在原时刻。点记录后可读讨论内容与原话；决定和待办默认折叠。原话详情的「… → 选择原话…」进入选择模式，选好后点「加入事项…」，可新建事项或加入当天已有事项。未选的句子仍在原时刻，手工归属保存在资料库，重新生成概述时会保留。无录音时显示录音与保存引导。
- **回听与查找录音。** 底栏时间尺直接按北京时间定位。播放速度对逐句、片段、原录音和连续回听统一生效。点原话钟点或播放按钮回听到句末；对话片段可点「播放这段」，事项可点「连续回听」。在句子或片段范围内拖动仍保持该范围，定位到范围外时切换到当天音频。翻看其他日期会继续播放，点底栏来源日期返回正在听的位置，也可从「录音 N」菜单改播当前浏览日期。没有可靠日期的原件仍可在原始录音页单独播放。
- **在归档录音中识别熟人。** 打开原件转写，在发言人菜单选择「填写名字」。工作留声会从本组发言中选取最多三段至少 3 秒、互不重叠的语音，在本地建立声纹。其他录音出现匹配时，可在同一菜单中确认、更正或忽略。只有手动命名或确认的录音才用于识别其他录音。
- **实时字幕与气泡。** 菜单栏显示录音卡状态、最近一句、同步或回听进度，也能临时隐藏气泡。默认使用本机识别。开启云端实时识别并配置密钥后，两路同时接收录音卡音频。每段本机短语就绪后，最多等 150 毫秒选取同段、稳定的云端文字；超时或网络失败就显示本机文字。检测到人声时，字幕页会提示「已收到声音」。桌面只显示已从本段蓝牙音频提取出声纹的发言，包括尚未确认身份的发言人。连续发言可在字幕定稿前出现。气泡跟随实时列表更新同一句话，识别器补写句首或改字时两处会一起修订。超过两行的气泡以省略号标出未展示的开头，列表保留全文。当天尚无已归档的录音时，主窗口默认进入实时字幕。最新发言显示在顶部，单击正文或时间只选中该句，新字幕继续显示。向下翻看、拖选文字或回听时，列表保留阅读位置，有新字幕时可点「回到最新」。字幕列表上方始终显示最近 24 小时的时间尺，左侧为昨天，右侧为现在。默认显示全部。在轨道上向左或向右拖出时段，两端竖杆和起止时间框可微调到分钟。调整范围或从设备详情返回时，会保留仍在结果里的阅读位置。空白时段可跳到前后最近一句。点「回到最新」恢复实时跟随。时刻以本机首次收到这句字幕为准。新版开始接收的蓝牙音频会按定稿字幕的起止位置缓存在 Mac 上，保留最近 24 小时。每句字幕正文下方直接显示转写来源和「回听」。有缓存音频时，直接点「回听」即可播放到句末；没有音频时按钮置灰。鼠标移入气泡时，整组气泡的背景和文字会变淡，移开后恢复；身份按钮和关闭按钮保持清晰。单击气泡正文或空白处即可收起这条气泡，也可点右上角的 ×；点击「是我 / 不是我」只校正身份，不关闭气泡。关闭只影响这一条气泡，实时字幕、历史文字和回听仍会保留，后续修订不会重新弹出已关闭的气泡。
- **在气泡上校正声纹。** 未确认的声音可点「是我」，误认本人可点「不是我」。右键点标注按钮也可直接确认当前判断，例如为未确认的发言选择「不是我」。本机会一起保存选中的录音卡音频片段、声纹和反馈。本人样本用于匹配，非本人样本帮助排除相似声音。右键可撤销该句标注。

实时身份会随连续音频更新，不必等整句定稿。后续句子可以利用同一声音的连续证据；只有当前语句中包含完整合格的声纹窗口时，反馈才登记新的样本，短句标注不会借用前一句的音频。设置页会提示与其他本人样本差异较大的样本，原样本保留。识别仍显示未知时，可在正常佩戴条件下补充清晰的本人发言。需要重新建立样本时，打开「设置 → 语音识别 → 本人识别样本库」，点「清空样本库…」并确认，可一次清除全部本人和非本人样本。录音、字幕、历史身份标注及其他发言人姓名保留；清空不可撤销，之后可重新标记发言。技术与验证边界见 [实时声纹](实时声纹.md)。
- **云端整理。** 在「设置 → 语音识别」开启百炼并填写北京地域 API Key，以使用云端转写、对话整理和全天摘要。密钥保存在 macOS 钥匙串。概述生成失败时点「重试概述」或在任务区点「重新生成概述」，会复用已有转写，忙时实际排队。尚有录音需要手动处理时，用实心蓝色「开始处理」按钮；已有新内容未计入时显示「更新概述」，不再用「等待更新」混合表达。正常完成后不常驻展示完成提示。
- **区分进度和操作。** 正在转写、提取事项或生成概述时显示转圈与阶段文字，不再显示启动按钮；确实进入队列时显示时钟和「将自动处理」。暂停后明确提示需要手动继续，未配置时提供「设置语音识别」。需要开始、继续或重试的操作统一为实心蓝色按钮；查看原件、同步详情等导航操作使用描边按钮。其他任务正在运行时，可将当前这一天加入处理队列；重复点击不会重复提交，也不会启动其他未选择日期。原始录音列表、原文详情、日期列表和后台任务使用相同判断，正常已完成的录音不常驻显示处理提示。
- **选择识别模型。** 「设置 → 语音识别」可分别选择实时字幕和完整录音的云端模型。实时字幕默认使用 3.1 Streaming，下次连接时应用新选择。完整录音默认使用支持区分发言人的 3.1 Flash，切换后从下一份待转写录音生效。已有部分转写的录音会沿用原模型完成。
- 选择实时字幕模型 **3.1 FileTrans** 时，本机直接出字幕。每段本机字幕定稿后，App 将对应的回听音频上传到百炼临时存储（48 小时），在后台转写。云端结果返回时，同一行的文字更新并标为「云端转写」，仍在显示的气泡也会同步更新。云端失败时保留本机文字，选中这句可重试。

默认资料库为 `~/Documents/工作留声/`，可在「设置 → 本地归档」查看和切换。备份整个资料库可保留 `Records/` 中的原件、转写和剪辑，`Days/` 中的全天摘要，以及 `Sync/` 中的字幕、归档和声纹记录。处理失败时可查看错误详情并从对应的日期或原件重试。


录音卡首次接入和实机对照见[录音卡使用指南](录音卡使用指南.md)。构建与测试见[开发指南](开发指南.md)。
