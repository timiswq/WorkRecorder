# 工作留声使用指南

主窗口顶部用一行原生窗口工具栏显示录音卡与 Mac 任务：左侧显示当前设备名称、录音状态、时长和电量，点击可进入录音卡详情；右侧用任务图标集中承载保存、转写、提取事项和生成概述；运行中用小蓝点提示，需要处理的失败用警示图标提示，悬停或点击可看具体内容并恢复操作。进入设备页后，设备名、录音状态和电量集中在正文，工具栏保留导航和 Mac 任务。菜单栏使用同一套状态与操作。后台转写失败不会把正在录音的卡标记成硬件故障；收起错误横幅只隐藏提示，任务中的失败和重试入口仍保留。

侧栏仅保留必要的设备与录音提示。「全天事项」不再常驻显示整理转圈和更新蓝点；后台任务集中在右上角。点击仍可打开最近有内容更新的日期，实际查看后清除对应版本。「实时字幕」在设备确认录音并收到音频时，用四个小方块表示真实输入音量，环境安静时保留空格轮廓；收不到音频时显示短横线，暂停、停止、连接中和未知状态分别表达。电平不依赖字幕识别开关，不使用呼吸动画。「原始录音」显示已知待同步段数，等待 USB、正在录音或清单过期时仍保留上次发现的数量，悬停可查看说明；不完整清单用「≥」表示已发现的至少数量。排除正在录制或待确认保存的文件，同一录音的配对文件合并计算；保存并校验完成后减数，无已知待同步项时隐藏。进入原始录音页可直接查看待同步清单、保存进度和同步操作，设备入口在连接时显示当前设备名，断开后显示「录音卡」。图标跟随工具栏的设备状态，录音时显示红色录音符号，暂停时显示暂停符号，USB 文件连接时显示接线符号。侧栏收起后也可悬停查看设备名和状态。

「全天事项」以日期、概述和分时记录为主。中间列表顶部固定显示日期、日历与前后切换，历史日期可点「今天」；跨年份时显示年份。概述默认最多四行，长内容可展开，决定与待办放入「更多信息」。上午、下午、晚上默认展开，空时段不显示；每条记录先显示时间、主题和一句预览，不重复标记整理状态或句数。右侧详情从自身标题开始，默认阅读原话。同一发言人的连续原话合并显示身份标签，仍可逐句回听和操作发言人。

底部统一提供播放、按钟点查找、速度和「录音 N」来源菜单。时间尺标出实际录音区间，点击空档定位到下一段可用音频；连续播放自动跳过空档。同一天不再重复日期，跨日期播放时显示来源日期并可返回。原件列表可从底栏查看原文、播放原录音或在访达中显示。窗口缩小时自动收紧播放控件，保留日期、来源和核心播放入口。

Dock 小助手随录音卡状态自动切换：未连接、连接中、待确认、未录音、正在录音、暂停、保存中和 USB 文件连接。身体下方的符号表示设备状态；未连接只表示 Mac 暂时无法确认卡上状态，USB 图标只表示文件连接。右上角系统角标同步显示「原始录音」的待同步数量，清单不完整时同样使用「≥」，数量超过 99 时显示「99+」。有角标时显示无嘴的提醒双眼，角标清空或暂不显示时恢复原表情；数字由 macOS 单独绘制。关闭主窗口后仍会更新。录音状态、音量、整理进度、更新蓝点和错误状态不增加 Dock 角标。

顶部以电池图标与百分比显示电量，充电时显示「充电中」；设备名在设备详情中查看。正在浏览其他页面时，录音卡新开始录音会将主窗口切到实时字幕并跟随最新内容：支持机身开始按键，也支持查询确认从未录音变为录音。暂停恢复、重连时首次获取状态和音频文件边界变化不会触发跳转；已经在字幕页回看时保留当前阅读位置。

主窗口与菜单栏从录音卡最近回复的时长开始逐秒计时，收到新回复时校准，暂停时停住。连续 10 秒未收到时长回复时，设备页隐藏时长，菜单栏提示时长待更新。电量取自最近一次有效回复。同一张卡通过 USB 接入后会暂停蓝牙音频和实时字幕，App 无法确认此时卡上是否仍在录音，请查看卡上指示。设备页以当前连接的设备名为标题。录音时可查看实时字幕，Wi-Fi 录音卡空闲时可同步，USB 接入时显示文件保存状态。未连接时标题为「录音卡」，可选择设备或重连上次的蓝牙设备。设备页列出传输方式和卡内录音数量。FW925 通过蓝牙报告容量，USB 接入后从当前卡的磁盘读取容量。取得有效读数后，页面同时显示总容量、已用空间和剩余空间。容量条标示已用比例。「技术信息」中可查看设备已提供的序列号、固件版本和设备标识。文件已保存、卡内副本已删除、文字整理已完成分别表达。完成文件操作并在访达中推出磁盘后，再断开 USB 恢复蓝牙字幕。

- **归档录音。** 在侧栏「录音卡」点「选择录音卡…」绑定设备，在录音卡上启停录音。首次接入 USB，在「设置 → 录音卡」将该盘关联到对应的蓝牙录音卡。蓝牙连接期间只接受这张卡的同步。蓝牙断开后，App 仍只识别上次选择的卡；要换卡或只用 USB，可在设备页点「切换设备…」并选择目标磁盘。接入选中的卡后，App 将已保存的录音复制到资料库并核对文件大小和 SHA-256。「设置 → 本地归档 → 同步后清理卡内副本」默认开启。如需在卡上另留一份，请在同步前关闭。关闭自动同步时，在主窗口左侧点设备名，再点「立即同步」。「导航」菜单显示同步目标，⌘R 按当前选择使用 USB 或 Wi-Fi。窗口右上角的菜单也可以导入本地音频。
- **查看同步进度。** USB 和 Wi-Fi 传输时，设备页显示当前文件、段序、已传字节及近期速度。进入校验后速度收起。完成时分别查看新增归档数、卡内副本和网络恢复结果。
- **查看全天事项。** 点日期打开日历，有录音的日期带圆点；点上午、下午、晚上可收起对应时段。一场会议可引用多份录音，零散原话以「对话片段」保留在原时刻。点记录后可读讨论内容与原话；决定和待办默认折叠。原话详情的「… → 选择原话…」进入选择模式，选好后点「加入事项…」，可新建事项或加入当天已有事项。未选的句子仍在原时刻，手工归属保存在资料库，重新生成概述时会保留。无录音时显示录音与保存引导。
- **回听与查找录音。** 底栏时间尺直接按北京时间定位。播放速度对逐句、片段、原录音和连续回听统一生效。点原话钟点或播放按钮回听到句末；对话片段可点「播放这段」，事项可点「连续回听」。在句子或片段范围内拖动仍保持该范围，定位到范围外时切换到当天音频。翻看其他日期会继续播放，点底栏来源日期返回正在听的位置，也可从「录音 N」菜单改播当前浏览日期。没有可靠日期的原件仍可在原始录音页单独播放。
- **在归档录音中识别熟人。** 打开原件转写，在发言人菜单选择「填写名字」。工作留声会从本组发言中选取最多三段至少 3 秒、互不重叠的语音，在本地建立声纹。其他录音出现匹配时，可在同一菜单中确认、更正或忽略。只有手动命名或确认的录音才用于识别其他录音。

## 实时字幕、气泡与发言人

在「设置 → 桌面语音气泡」打开「使用 Mac 麦克风」，首次使用时允许麦克风访问。录音卡和 Mac 内置麦克风各自使用苹果本机中文识别，桌面气泡标明来源。只有一路听到时，只显示该路的气泡。即使录音卡没有连接，也可以看麦克风气泡。关闭开关即停止麦克风采集。麦克风音频和字幕仅在内存中用于气泡，录音卡的字幕历史、云端设置和声纹仍按原设置处理。

- **听到开口。** 字幕页提示「已收到声音」，桌面显示声波。第一个稳定短语在同一个气泡中淡入。即使只有一个「嗯」，也可以显示文字，发言人暂时显示为「未知发言人」。
- **阅读气泡。** 已经出现的字固定在原处，后续短语接在句尾。如果识别器把同一句重新切成两段，气泡会接着显示尚未读到的词。两行写满后另起一条气泡。开启系统「减弱动态效果」时，短语直接出现。
- **操作气泡。** 鼠标移入时，文字与背景变淡，身份和关闭按钮保持清晰。单击正文、空白处或右上角的 × 可收起当前气泡。收起的录音卡字幕仍可在主窗口查看、回听。菜单栏可临时隐藏全部气泡，也能查看录音卡状态、最近一句和同步或回听进度。
- **查看历史。** 主窗口按首次收到字幕的时间排列，最新一句在顶部。当天尚无已归档录音时，主窗口默认打开实时字幕。单击正文或时间可选中该句。向下翻看、拖选文字或回听时，列表会保留阅读位置，点「回到最新」恢复跟随。
- **筛选和回听。** 时间尺默认显示最近 24 小时。拖动轨道选取时段，再拖动两端或用时间框微调到分钟。调整范围或从设备详情返回时，会保留仍在结果里的阅读位置。空白时段可以跳到前后最近一句。每句下方显示转写来源。定稿且有蓝牙音频缓存时，点「回听」即可播放到句末，缓存保留 24 小时。

### 标注发言人

在主窗口点一句字幕的发言人，或将鼠标移到桌面气泡上，选择「是我」或「不是我」。气泡上的按钮也支持右键选择另一项，标注后右键可撤销。标注不会收起气泡。

| 标注时这句话的音频 | 标注结果 |
| --- | --- |
| 本句音频够长，已有可用声纹 | 气泡显示「已存本人样本」或「已存非本人样本」。后续识别用本人样本匹配声音，用非本人样本排除相似声音。 |
| 音频太短、没有可用声纹，或只能借前一句判断身份 | 显示「仅标注本句」。即使后来识别出声纹，这次标注也不会自动加入样本库。 |

在「设置 → 语音识别 → 本人识别样本库」可以查看样本数量，以及与其他本人样本差异较大的样本提示。可在正常佩戴录音卡时标注一段清晰的本人发言，补充样本。点「清空样本库…」并确认，会删除所有本人和非本人样本，录音、字幕、历史身份标注及其他发言人姓名保留。清空不可撤销。[实时声纹](实时声纹.md)

## 云端转写与整理

默认使用本机字幕。开启 ESP 云端实时识别并配置密钥后，两路同时接收录音卡音频。每段本机短语就绪后，最多等 150 毫秒选取同段、稳定的云端文字。超时或网络失败时显示本机文字。字幕历史保留整句的最新转写。

- **云端整理。** 在「设置 → 语音识别」开启 ESP 并填写平台 API Key，以使用云端转写、对话整理和全天摘要。对话整理与概述使用 `gpt-6.1-sol`。密钥保存在 macOS 钥匙串。概述生成失败时点「重试概述」或在后台任务点同一天的「重试概述」，会复用已有转写，忙时实际排队。尚有录音需要手动处理时，用实心蓝色「开始处理」按钮；已有新内容未计入时显示「更新概述」，不再用「等待更新」混合表达。正常完成后不常驻展示完成提示。
- **区分进度和操作。** 正在转写、提取事项或生成概述时显示转圈与阶段文字，不再显示启动按钮；确实进入队列时显示时钟和「将自动处理」。暂停后明确提示需要手动继续，未配置时提供「设置语音识别」。后台任务按日期各显示一条：录音待转写时点「开始转写」，仅概述失败时点「重试概述」。错误原因显示在同一条内，排队和运行中显示进度，完成后该条消失。正常的实时字幕可从侧栏查看。需要开始、继续或重试的操作统一为实心蓝色按钮；查看原件、同步详情等导航操作使用描边按钮。其他任务正在运行时，可将当前这一天加入处理队列；重复点击不会重复提交，也不会启动其他未选择日期。原始录音列表、原文详情、日期列表和后台任务使用相同判断，正常已完成的录音不常驻显示处理提示。
- **选择实时字幕模型。** 在「设置 → 语音识别」选择 3.1 Streaming 或 3.1 Message，下次连接云端时生效。完整录音使用 ESP 的 3.1 Flash 获取文字、时间戳和发言人编号。旧版 Flash 3.0 的归档断点会保留已转写的分段，其余分段由 3.1 Flash 继续。
- **逐句复核。** 选择「3.1 Flash（逐句复核）」时，本机先出字幕。每句定稿后，App 把该句音频直接发给 ESP，收到文字后只更新字幕历史的原行。失败时保留本机文字，点选该句可重试。旧版 FileTrans 设置自动迁移到这个选项。

默认资料库为 `~/Documents/工作留声/`，可在「设置 → 本地归档」查看和切换。备份整个资料库可保留 `Records/` 中的原件、转写和剪辑，`Days/` 中的全天摘要，以及 `Sync/` 中的字幕、归档和声纹记录。处理失败时可查看错误详情并从对应的日期或原件重试。


录音卡首次接入和实机对照见[录音卡使用指南](录音卡使用指南.md)。构建与测试见[开发指南](开发指南.md)。

## Wi-Fi 录音卡（B3085 / FW925）

蓝牙已连接且卡空闲时，打开设备页即可查看「卡内录音」的总段数和待同步段数。工作留声通过蓝牙读取清单，再与这张卡在当前 Mac 资料库中校验通过的归档比对。查看数量时 Mac 保持原来的 Wi-Fi 连接。若正在录音，保存后页面会自动更新。

1. 打开侧栏的设备入口（已连接时显示设备名），点「选择录音卡…」或「切换设备…」，在标为「蓝牙 + Wi-Fi」的设备旁点「使用」。浏览和关闭列表会保留当前连接，选定另一张卡后才切换。断开蓝牙只会结束 Mac 的实时接收，机身录音仍由卡上按键控制。
2. 要边录边看字幕，请保持蓝牙连接，在卡上开始录音，打开「实时字幕」。工作留声收到可解码的蓝牙音频后，会沿用现有的本机字幕、云端字幕和声纹设置。若一直显示「暂未收到实时音频」或「实时音频暂不可用」，可以在录完后同步原件。
3. 在卡上结束并保存录音。在「录音卡」页或菜单栏点「同步录音」。首次使用按系统提示允许蓝牙、本地网络与用于识别热点的定位权限。Mac 临时加入卡的热点，同步期间无线互联网可能中断。
4. 等待显示录音读取、归档和网络恢复结果。若手动换了网络，App 会保留你的选择。恢复失败时可点「Wi-Fi 设置…」重新选择原网络。
5. 到「录音库」回听，按已有的语音识别和整理设置处理。当前版本将这款卡的录音归在「日期未知」，导入时间单独保留。每段录音的目录里保留设备原件 device.bin 和可播放的 original.wav。
6. 在「设置 → 本地归档」用「同步后清理卡内副本」统一控制 USB 和 Wi-Fi。开启时，FW925 在完整读取并校验本地归档后，通过蓝牙清理对应副本。已经归档的卡内历史录音也会核对原件内容。保留卡内录音时可关闭此设置。
7. 下载中取消可在下次同步时续传。解码失败可点「重试本地归档」。有待清理的副本时，可点「重试清理卡内副本」，App 会在下一次同步中重新核对。
