# 工作留声使用指南

主窗口顶部用一行原生窗口工具栏显示录音卡与 Mac 任务：左侧是录音、时长和电量，点击可进入录音卡详情；右侧是保存、转写、整理或待处理事项，点击展开任务并恢复操作。切换日期和页面时，全局状态持续可见。菜单栏使用同一套状态与操作。后台转写失败不会把正在录音的卡标记成硬件故障；收起错误横幅只隐藏提示，任务中的失败和重试入口仍保留。

侧栏使用少量局部提示。「全天事项」整理时显示小转圈；事项或全天总结有尚未查看的内容更新时显示蓝点，优先保留更新提示。点击会打开最近有更新的日期，实际在前台查看该日期的总结后清除对应版本，其他日期仍保留；重复生成相同内容不会制造更新。「实时字幕」在设备确认录音并收到音频时，用四个小方块表示真实输入音量，环境安静时保留空格轮廓；收不到音频时显示短横线，暂停、停止、连接中和未知状态分别表达。电平不依赖字幕识别开关，不使用呼吸动画。「原始录音」显示已知待同步段数，等待 USB、正在录音或清单过期时仍保留上次发现的数量，悬停可查看说明；不完整清单用「≥」表示已发现的至少数量。排除正在录制或待确认保存的文件，同一录音的配对文件合并计算；保存并校验完成后减数，无已知待同步项时隐藏。进入原始录音页可直接查看待同步清单、保存进度和同步操作，录音卡入口不挂数字。

日期导航位于「全天事项」中间列表分栏的固定页头，右侧详情直接从顶部开始，与当天原件数量一起固定显示；点日期展开日历，左右箭头逐日切换，历史日期可点「回到今天」。实时字幕、原始录音和录音卡各自显示局部范围与操作。宽窗口的事项和原件列表使用可拖动分栏，窄窗口保留列表与详情的返回路径。全天总结默认两行，点「展开摘要与待办」查看完整内容。全天分布与钟点定位合并为一条默认折叠的时间尺；底部播放器按有效音频时长定位，并标明正在回听的来源日期和范围。

Dock 图标同步显示「原始录音」的待同步数量，清单不完整时同样使用「≥」，数量超过 99 时显示「99+」。关闭主窗口后仍会随同步结果更新，无已知待同步项时清除。录音状态、音量、整理进度、更新蓝点和错误状态不增加 Dock 角标。

顶部电量带有电池图标与「电量」说明，充电时显示「充电中」；设备名在设备详情中查看。正在浏览其他页面时，录音卡新开始录音会将主窗口切到实时字幕并跟随最新内容：支持机身开始按键，也支持查询确认从未录音变为录音。暂停恢复、重连时首次获取状态和音频文件边界变化不会触发跳转；已经在字幕页回看时保留当前阅读位置。

主窗口与菜单栏从录音卡最近回复的时长开始逐秒计时，收到新回复时校准，暂停时停住。连续 10 秒未收到时长回复时，不再继续推算，设备页和菜单栏提示「时长暂未更新」。电量取自最近一次有效回复。USB 接入会暂停蓝牙音频和实时字幕，App 无法确认此时卡上是否仍在录音，请查看卡上指示。「录音卡」页先显示原件保存结果和当前可执行操作，再显示连接影响与 Mac 任务；绑定、容量、固件、磁盘名和设备设置放在折叠详情中。文件已保存、卡内副本已删除、文字整理已完成分别表达。完成文件操作并在访达中推出磁盘后，再断开 USB 恢复蓝牙字幕。

- **归档录音。** 在「设置 → 录音卡」绑定设备，在录音卡上启停录音。通过 USB 接入 Mac 后，App 将已保存的录音复制到资料库，核对文件大小和 SHA-256 后清理卡内对应副本。关闭自动同步时，在主窗口左侧的「录音卡」点「立即同步」。窗口右上角的菜单也可以导入本地音频。
- **查看全天事项。** 日历用圆点标出有录音的日期。事项按上午、下午和晚上分组，点时段标题可以整组收起或展开。一场会议可以引用多份录音。简短的分工或约定显示为时间点。未整理对话按原时刻穿插在时间线上，可切换到「未整理」逐句回听。30 秒以内的对话默认使用紧凑回听控件，可按需展开波形。勾选原话后点「补整理」，可新建事项或补进当天已有事项。未选的句子仍留在原时刻，手工归属保存在本地资料库，重新生成全天摘要时会保留。当天页头显示 Mac 上已保存的原件，录音卡状态留在全局工具栏；当天无原件时显示录音与同步引导。点开事项可看决定和原话，也可按当天日期查看原始录音。
- **全天回听。** 底部进度条按有效音频时长定位，跨原件连续播放，自动跳过无录音时段。按北京时间定位可展开时间线上方的「全天分布与时间定位」。翻看其他日期时继续播放，点底栏的播放日期可回到正在听的位置。点某句原话的钟点或播放按钮，可以从那句话开始回听。没有可靠日期的原件可在资料库单独播放。
- **在归档录音中识别熟人。** 打开原件转写，在发言人菜单选择「填写名字」。工作留声会从本组发言中选取最多三段至少 3 秒、互不重叠的语音，在本地建立声纹。其他录音出现匹配时，可在同一菜单中确认、更正或忽略。只有手动命名或确认的录音才用于识别其他录音。
- **实时字幕与气泡。** 菜单栏显示录音卡状态、最近一句、同步或回听进度，也能临时隐藏气泡。默认使用本机识别。开启云端实时识别并配置密钥后，两路同时接收录音卡音频。每段本机短语就绪后，最多等 150 毫秒选取同段、稳定的云端文字；超时或网络失败就显示本机文字。检测到人声时，字幕页会提示「已收到声音」。桌面只显示已从本段蓝牙音频提取出声纹的发言，包括尚未确认身份的发言人。连续发言可在字幕定稿前出现。气泡跟随实时列表更新同一句话，识别器补写句首或改字时两处会一起修订。超过两行的气泡以省略号标出未展示的开头，列表保留全文。当天尚无已归档的录音时，主窗口默认进入实时字幕。最新发言显示在顶部，单击正文或时间只选中该句，新字幕继续显示。向下翻看、拖选文字或回听时，列表保留阅读位置，有新字幕时可点「回到最新」。字幕列表上方始终显示最近 24 小时的时间尺，左侧为昨天，右侧为现在。默认显示全部。在轨道上向左或向右拖出时段，两端竖杆和起止时间框可微调到分钟。调整范围或从设备详情返回时，会保留仍在结果里的阅读位置。空白时段可跳到前后最近一句。点「回到最新」恢复实时跟随。时刻以本机首次收到这句字幕为准。新版开始接收的蓝牙音频会按定稿字幕的起止位置缓存在 Mac 上，保留最近 24 小时。每句字幕正文下方直接显示转写来源和「回听」。有缓存音频时，直接点「回听」即可播放到句末；没有音频时按钮置灰。将指针移到某一句，点右上角的 × 可提前收起这条气泡，转写文字仍会保留。
- **在气泡上校正声纹。** 未确认的声音可点「是我」，误认本人可点「不是我」。右键点标注按钮也可直接确认当前判断，例如为未确认的发言选择「不是我」。本机会一起保存选中的录音卡音频片段、声纹和反馈。本人样本用于匹配，非本人样本帮助排除相似声音。右键可撤销该句标注。
- **云端整理。** 在「设置 → 语音识别」开启百炼并填写北京地域 API Key，以使用云端转写、对话整理和全天摘要。密钥保存在 macOS 钥匙串。当天摘要失败时，点「重试这一天」会复用已有转写，忙时排队，成功后替换已保存的摘要。
- **选择识别模型。** 「设置 → 语音识别」可分别选择实时字幕和完整录音的云端模型。实时字幕默认使用 3.1 Streaming，下次连接时应用新选择。完整录音默认使用支持区分发言人的 3.1 Flash，切换后从下一份待转写录音生效。已有部分转写的录音会沿用原模型完成。
- 选择实时字幕模型 **3.1 FileTrans** 时，本机直接出字幕。每段本机字幕定稿后，App 将对应的回听音频上传到百炼临时存储（48 小时），在后台转写。云端结果返回时，同一行的文字更新并标为「云端转写」，仍在显示的气泡也会同步更新。云端失败时保留本机文字，选中这句可重试。

默认资料库为 `~/Documents/工作留声/`，可在「设置 → 本地归档」查看和切换。备份整个资料库可保留 `Records/` 中的原件、转写和剪辑，`Days/` 中的全天摘要，以及 `Sync/` 中的字幕、归档和声纹记录。处理失败时可查看错误详情并从对应的日期或原件重试。
