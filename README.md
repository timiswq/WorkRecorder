# 工作留声

工作留声是配合 QS668 / CB08 录音卡使用的原生 macOS 应用。当前开发基线为 **0.5.3（20260004）**，对应本地 Git 标签 `baseline-2026-11-11`。

## 日常使用

- **归档录音。** 在「设置 → 录音卡」绑定设备，在录音卡上启停录音。通过 USB 接入 Mac 后，App 将已保存的录音复制到资料库，核对文件大小和 SHA-256 后清理卡内对应副本。关闭自动同步时，在「设备与资料库 → 录音卡」点「立即同步」。窗口右上角的菜单也可以导入本地音频。
- **查看全天事项。** 日历用圆点标出有录音的日期。一天按上午、下午和晚上呈现，一场会议可以引用多份录音。简短的分工或约定显示为时间点，零散交流默认收起。点开事项可看结果、决定和原话，也可返回原件。
- **全天回听。** 底部进度条按北京时间定位，跨原件连续播放，自动跳过无录音时段。点某句原话的钟点或播放按钮，可以从那句话开始回听。没有可靠日期的原件可在资料库单独播放。
- **实时字幕与气泡。** 菜单栏显示录音卡状态、最近一句、同步或回听进度，也能临时隐藏气泡。气泡使用本机中文语音识别。将指针移到某一句时，漏认本人可点「是我」，误认本人可点「不是我」。右键可撤销该句标注。有对应的本句音频时，反馈用于本机声纹匹配。
- **云端整理。** 在「设置 → 语音识别」开启百炼并填写北京地域 API Key，以使用云端转写、对话整理和全天摘要。密钥保存在 macOS 钥匙串。当天摘要失败时，点「重试这一天」会复用已有转写，忙时排队，成功后替换已保存的摘要。

默认资料库为 `~/Documents/工作留声/`，可在「设置 → 本地归档」查看和切换。备份整个资料库可保留 `Records/` 中的原件、转写和剪辑，`Days/` 中的全天摘要，以及 `Sync/` 中的归档和声纹记录。处理失败时可查看错误详情并从对应的日期或原件重试。

## 开发与验证

在本仓库打开 `WorkRecorder.xcodeproj`，选择 **WorkRecorder → My Mac**。部署目标为 macOS 14；本机语音验收需支持对应 Apple 中文识别模型。App 入口在 `WorkRecorder/`，Mac 界面在 `Sources/WorkdayMac/`，归档、语音与事项整理在 `Sources/WorkdayCore/`，录音卡协议在 `Sources/QS668Core/`。随包模型和第三方许可由工程管理。

```sh
./script/build_and_run.sh --build-only
./script/test.sh
./script/test.sh --full
./script/package_dmg.sh
```

构建和测试默认输出到 `~/Documents/CodexArtifacts/WorkRecorder/开发构建/`，也可通过 `WORKDAY_ARTIFACTS` 指定其他仓库外目录。打包脚本使用该目录中已构建的 Release App，生成 Apple Silicon 的本地签名 DMG。

`--full` 使用公开说话人音频、合成的录音卡音频和示例资料库，覆盖桌面气泡、原生窗口、全天播放和长录音归档。默认输入在 `~/Documents/CodexArtifacts/WorkRecorder/2026-11-11-开发基线/fixtures/`；换机器可复制该目录并通过 `WORKDAY_FIXTURES` 指向它。窗口测试在临时副本上运行。普通测试不要求这组外部输入。

后续改动从本仓库的 `main` 开始。使用 `git diff baseline-2026-11-11..HEAD` 可查看相对本次基线的改动。
